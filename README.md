## Preserved behavior

Sticky header with always-accessible Contacts, accented call/email/Telegram actions, and transparent text-selection background. UI arrows rest northeast and become horizontal right on hover/focus; scroll does not rotate them.

Most sections react through decorative layers only: hero photograph and roses, mood bouquets, game sprigs, composer bouquet, manifesto rose, map lines/flower, callback atmosphere and footer mark. Controls and text remain stationary; overlays do not receive pointer events. Touch, keyboard and reduced-motion behavior are preserved. Animation frames stop when settled, offscreen or hidden.

The six-pair memory game closes mismatches automatically after one second, announces completion and supports reset. The bouquet composer saves only after an explicit action and does not place an order. The enquiry form validates, shows an honest demo confirmation, clears name/phone and supports retry; no personal data is sent or stored by this form.
